Import industry ontologies

Explore the publishers’ websites and follow their download steps below, or use the provided lab TTL downloads.

  1. IOF Core

    Industrial Ontologies Foundry Core reference ontology.

    Visit official IOF Core website ↗Download IOF Core TTL

    Lab download: Turtle · 312 KB · IOF release 202602.

    How to download from the official IOF site
    1. Open the IOF Core overview to explore its purpose, classes and relationships.
    2. Open core/Core.rdf in the official IOF repository. The link selects release 202602.
    3. Select Download raw file near the file toolbar and save Core.rdf. Alternatively, right-click the official raw Core.rdf file and choose Save link as.

    IOF publishes this file as RDF/XML. For the HOL’s Turtle-file upload, use the Download IOF Core TTL button above.

  2. FIBO Quick Start

    Financial Industry Business Ontology full reference download.

    Visit official FIBO website ↗Download FIBO Quick Start TTL

    Lab download: Turtle · 8.3 MB · FIBO release 2026Q2.

    How to download from the official FIBO site
    1. Open the official FIBO website. Explore its model in FIBO Viewer, or choose Products → FIBO OWL to learn about formats and releases.
    2. Open the official Production Quick Start Turtle file, release 2026Q2. This publisher-hosted file matches the lab download.
    3. If Turtle text appears in the browser, choose Save as, or right-click the official file link and choose Save link as. Save it as fibo_quickstart.ttl.

    The FIBO OWL page also offers Download FIBO OWL through EDMConnect, which may request sign-in. The direct official 2026Q2 link above is the verified route for this lab file.
