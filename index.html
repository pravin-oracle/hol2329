FIBO Products and Services

Explore clients, accounts, financial products and services with a FIBO teaching slice prepared for this lab: 100 business classes, 198 classes total including supporting concepts and helpers, 11 attributes and 203 relationships.

Download prepared FIBO lab ZIP

ZIP · 33 KB · fibo_products_services.zip

Import the prepared package

  1. In Workbench, select your own workspace. Open Ontologies → Create → Upload from a file and choose the downloaded ZIP.
  2. Set Name to fibo_products_services and Default Namespace to https://ontology.oracle.com/aidp/fibo_products_services/.
  3. Leave additional catalog sources and the business glossary empty, then select Import Zip.
  4. Explore the classes, attributes and relationships in the Ontology Editor as a draft.

Validation was checked in the lab: 0 errors, 0 blockers, with one duplicate-label warning for applies to.

Explore the official FIBO model and source files
  1. Open Products and Services in the official FIBO Viewer to browse the concepts and their definitions.
  2. View the original Turtle files from FIBO release 2026Q2: Clients and Accounts TTL and Financial Products and Services TTL.
  3. If a source file opens as text, choose Save as, or right-click its link and choose Save link as.

The official files retain FIBO’s dependencies and modeling constructs. The prepared lab ZIP contains the subset adapted for this tasklet. Learn more on the official FIBO website.
